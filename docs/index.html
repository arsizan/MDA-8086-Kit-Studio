MDA-8086 Kit Studio

Software for the MDA-8086 microprocessor trainer kit. Write 8086 assembly, assemble it, try it in a simulator of the kit, then send it to the real kit over the serial cable. One program: no DOSBox, emu8086 or TASM needed.

What it does

Kit simulator

8×8 dot matrix, 7-segment display, 4 LEDs, 16×2 LCD, registers, flags and both 8255s. Run at the real kit's speed (F6), step one instruction at a time (F8), pause (F9) or slow it down.

Run on the kit

F5 assembles, finds the kit on a COM port (9600 8N1), downloads the program and starts it at 0000:1000. A monitor box sends commands such as D and R.

Assembler with hints

Built-in JWasm assembler (F7) that makes the kit's .ABS file and shows the machine code. Errors come with a plain-language hint; double-click one to jump to its line.

Kit check

Before sending, the program runs on an 8086 model and warns about unknown ports, a missing 8255 setup, INT 21H, 80186+ instructions and running off the end of the program.

Examples and templates

7-segment count 0–9, three-colour dot-matrix rows, the letter A and a scrolling A, plus two program templates, all built in.

Windows and Linux

One small Win32 program for Windows XP to 11 and a GTK 3 program for 64- and 32-bit Linux. Runs from a pendrive; nothing to install on lab PCs.

Use it with the MDA-8086 kit

  1. Connect the kit's 9-pin RS-232 cable to a COM port, or to a USB-to-RS232 adapter (FTDI or CH340 chips work well).
  2. Set the kit's SELECT MODE switch to PC and turn it on.
  3. Write the program, or start from Templates. Begin with ORG 1000H and set up the 8255 first: MOV AL,80H then OUT 1EH,AL (dot matrix) or OUT 1FH,AL (7-segment, LEDs).
  4. Press F6 to try it in the simulator, then F5 to run it on the kit. If the kit does not answer, press its RESET.

Questions

Is it free?

Yes. Download it from the GitHub releases page; the full source code is in the repository.

Windows says "Windows protected your PC". Is it safe?

The program is not signed with a paid certificate, so Windows does not know it yet. Right-click the zip, choose Properties, tick Unblock, then extract it. Or click More info, then Run anyway.

Can I use it without the kit?

Yes. The simulator runs your program and shows the dot matrix, 7-segment display, LEDs, LCD, registers and ports, so you can practise at home.

Linux says I have no permission for the serial port.

Run sudo usermod -aG dialout $USER once, then log out and in again (on Arch and Manjaro the group is uucp). The simulator needs no permission.

It says "Kit not found".

Check the kit's power, that SELECT MODE is on PC and that the cable is in. Press RESET on the kit while Kit Studio is waiting.
